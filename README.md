# Рабочий кабинет — Северная линия

Приложение координатора проектов на Python и Streamlit: задачи, встречи,
материалы и резервное копирование в одном светлом рабочем пространстве.
Рассчитано на работу с мобильного телефона и с компьютера, внешние сервисы
и базы данных не требуются.

## Назначение

«Рабочий кабинет» помогает координатору компании «Северная линия» вести
операционный план: загружать рабочий план из Excel, следить за статусами
задач и сроками, готовиться к встречам, прикладывать материалы и забирать
с собой резервную копию. Интерфейс на русском языке, оформление —
спокойная деловая палитра по фирменному референсу.

## Разделы

| Раздел | Что делает |
|---|---|
| **Обзор** | Три показателя по отфильтрованным задачам — всего, выполнено, просрочено — с выбранной контрольной датой (исходно 09.11.2026). Просрочена незавершённая и неотменённая задача со сроком строго раньше контрольной даты. |
| **Задачи** | Загрузка рабочего плана (XLSX с листами «Проекты», «Сотрудники», «Задачи», «Встречи»), фильтры по проекту и сотруднику, таблица с подсветкой статусов и смена статуса выбранной задачи. |
| **Календарь** | Выбор недели и список встреч по дням: время, тема, проект, место, участники. |
| **Материалы** | Загрузка файлов DOCX/TXT (до 5 МБ на файл, до 20 МБ суммарно), привязка к проекту, список и скачивание оригинала. |
| **Отчёты** | Выгрузка текущей выборки задач в CSV (кодировка UTF-8 с BOM, разделитель «;» — открывается в Excel). |
| **Резервная копия** | Скачивание ZIP со всеми данными и оригиналами материалов, проверка и подтверждение при восстановлении. |

Статусы задач подсвечиваются приглушёнными цветами: серо-голубой — новая,
синий — в работе, янтарный — ожидает, зелёный — выполнена, серый — отменена.

## Принципы работы

- **Данные живут в сеансе.** Проекты, сотрудники, задачи, встречи и материалы
  хранятся в состоянии сеанса браузера. Никаких общих папок с загрузками,
  внешних баз и автосохранения между посещениями нет. Перед выходом скачайте
  резервную копию (ZIP) — при следующем посещении загрузите её в разделе
  «Резервная копия». Напоминание об этом видно постоянно.
- **Коды записей сохраняются.** Коды из исходных материалов — `PR-XX`
  (проекты), `EMP-XX` (сотрудники), `TSK-XXX` (задачи), `MTG-XXX` (встречи) —
  служат ключами связей и не изменяются и не переиспользуются. Все сущности
  связаны по кодам: задача → проект и ответственный, встреча → проект и
  участники, материал → проект.
- **Загрузка только по действию пользователя.** Исходные данные не подхватываются
  автоматически. Повторная загрузка рабочего плана полностью заменяет набор
  проектов, сотрудников, задач и встреч — дубли не накапливаются.
- **Проверка перед заменой.** Файл плана и архив резервной копии проверяются
  целиком до применения: обязательные столбцы и листы, корректность дат и
  времени, уникальность и формат кодов, ссылки на проекты и сотрудников,
  лимиты размера. При любой ошибке текущие данные остаются без изменений,
  а список проблем выводится пользователю. Архив обрабатывается в памяти,
  без извлечения на диск.
- **Содержимое материалов не исполняется.** Файлы хранятся как байты
  оригинала и отдаются на скачивание как есть.
- **Мобильная версия.** На узком экране показатели и поля выстраиваются в
  колонку, кнопки и поля — от 44 px под палец, широкие таблицы прокручиваются
  по горизонтали, напоминание о резервной копии показывается в основной
  области (сайдбар на телефоне свёрнут).

## Запуск локально

Требуется Python 3.10+.

```zsh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Или короткой командой: `./run.sh` (порт 8501).
Приложение откроется на http://localhost:8501 и будет пустым — это нормально.

## Как пользоваться

1. Откройте раздел **«Задачи»** и загрузите рабочий план — XLSX с листами
   «Проекты», «Сотрудники», «Задачи», «Встречи». После проверки данные
   заменят текущие, коды записей сохранятся.
2. В **«Обзоре»** оцените объём: всего, выполнено, просрочено — по проекту
   или сотруднику и контрольной дате.
3. В **«Задачах»** фильтруйте список и меняйте статусы по ходу сверки;
   в **«Календаре»** смотрите встречи по неделям.
4. В **«Материалах»** приложите документы и привяжите их к проекту.
5. В **«Отчётах»** выгрузите выборку задач в CSV для рассылки.
6. Перед выходом скачайте **резервную копию** (ZIP) — в ней все данные,
   оригиналы материалов и их связи. В следующий раз загрузите этот файл
   в разделе «Резервная копия» и подтвердите замену.

## Публикация

Публикуйте только эти файлы:

- `app.py`
- `requirements.txt`
- `run.sh` (необязательно)
- `README.md`
- пакет `cabinet/` целиком (`__init__.py`, `model.py`, `theme.py`,
  `components.py`, `sections/`)
- `.streamlit/config.toml` (светлая тема; именно `config.toml`, а не секреты)

**Не публикуйте:** `data_input/` (исходные материалы), `design_reference/`,
`exports/`, `backups/`, `.streamlit/secrets.toml` и любые файлы с секретами —
всё перечисленное исключено через `.gitignore`.

Например, для Streamlit Community Cloud достаточно положить файлы в
репозиторий и указать `app.py` как основной скрипт: внешних API и баз нет.
Каждый посетитель начинает с пустого кабинета и загружает свои материалы сам.

## Структура проекта

```
office-cabinet/
├── app.py                     # точка входа: тема, навигация, напоминание
├── run.sh                     # запуск на порту 8501
├── requirements.txt           # streamlit, pandas, openpyxl
├── .streamlit/config.toml     # светлая тема в цветах референса
└── cabinet/
    ├── model.py               # модель данных, валидация импорта и архивов, CSV
    ├── theme.py               # палитра оформления и цвета статусов
    ├── components.py          # шапки, показатели, пустые состояния, подсветка
    └── sections/              # Обзор, Задачи, Календарь, Материалы,
                                # Отчёты, Резервная копия
```

## Ограничения

- Данные сеанса теряются при закрытии вкладки без резервной копии —
  это осознанное правило приватности, а не ошибка.
- Материалы принимаются в форматах DOCX и TXT с лимитами 5 МБ на файл
  и 20 МБ на сеанс; текст файлов не разбирается.
- Выгрузка CSV и архив резервной копии формируются в памяти браузера
  стандартными средствами Streamlit.

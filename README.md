# Рабочий кабинет — Северная линия

Приложение координатора на Python и Streamlit: задачи, календарь встреч,
материалы, обзор, отчёты и резервная копия. Данные пользователя хранятся
только в сеансе браузера; при первом открытии кабинет пустой.

## Запуск локально

```zsh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Или командой `./run.sh` (порт 8501). Приложение откроется на
http://localhost:8501.

## Публикация

Публикуйте только эти файлы:

- `app.py`
- `requirements.txt`
- `run.sh` (необязательно)
- `README.md`
- пакет `cabinet/` целиком (`__init__.py`, `model.py`, `theme.py`,
  `components.py`, `sections/`)

**Не публикуйте:** `data_input/` (исходные материалы), `design_reference/`,
`exports/`, `backups/` (выгрузки и архивы), `.streamlit/secrets.toml` и любые
файлы с секретами. Всё перечисленное исключено через `.gitignore`.

Например, для Streamlit Community Cloud: положите файлы в репозиторий и
укажите `app.py` как основной скрипт — внешних API и баз не требуется.
Каждый пользователь начинает с пустого кабинета и загружает свой рабочий
план сам.
